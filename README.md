# Neovim Configuration

My personal Neovim configuration, focused on a productive development workflow.

## Features

* LSP, autocompletion, diagnostics, and formatting
* Git integration
* Fuzzy finding and file navigation
* Treesitter-based syntax highlighting
* Debugging support
* CMake and development tooling
* Custom keybindings and Lua configuration
* Curated collection of plugins for C++, Rust, Python, and other development work

The configuration is primarily built from existing plugins, with additional Lua configuration and customizations for my workflow.
